# dashboard_vendas 📊
Desenvolvimento de um dashboard de vendas de planos do Xbox Game Pass com outras assinaturas inclusas também como EA Play Season Pass e Minicraft Season Pass,
mostrando a quantidade recebida da venda anual, trimestral e mensal

# funcionalidades ⚙️
 - Demonstrar a quantidade de vendas anual, trimestral e mensal do Xbox Game Pass por meio de um gráfico de barras separados de acordo com a auto renovação da assinatura;
 - Demonstrar o valor em reais referentes a vendas do EA Play Season Pass e Minicraft Season Pass, também de forma anual, trimestral e mensal

# base de dados 🗃️

- A base de dados utilizada foi uma base fictícia contendo as seguintes colunas:

| Subscriber ID | Name | Plan | Start Date | Auto Renewal | Subscription Price | Subscription Type | 
| --- | --- | --- | --- | --- | --- | --- |

| EA Play Season Pass | Minicraft Season Pass | Minicraft Season Pass Price | Coupon Value | Total Value | 
| --- | --- | --- | --- | --- |

# organização e ferramentas 🛠️

- O projeto foi desenvolvido utilizando o Excel

- A organização do projeto foi realizada da seguinte forma:
    - **assets**: aba para armazenar imagens, paleta de cores e demais recursos visuais;
    - **base**: aba para armazenar a base de dados utilizada para a criação do dashboard;
    - **cálculos**: aba para realizar os cálculos necessários para transformar os dados em informações de acordo com as perguntas de negócio;
    - **dashboard**: aba na qual o dashboard foi construído de fato.
